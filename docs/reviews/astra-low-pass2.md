# Astra-low 번역 품질 리뷰: 2차

## 판정

1차 R1~R6은 모두 해소되었습니다. 한국어 문장 품질은 양호하며, 1차에서 읽은 WOTR-Enhance 표본과 비교해도 준수합니다. 다만 이번 용어 정리 과정에서 발견한 **P2-1과 P2-2를 수정한 뒤 용어 정합성을 승인**하는 것이 적절합니다. P2-3도 목록 가독성을 위해 함께 수정할 것을 권합니다.

이 판정은 번역 품질에 관한 것입니다. 전체 빌드 성공, 게임 실행 성공, 모든 효과의 실기 검증이나 배포 승인을 뜻하지 않습니다.

## 실제 검토 범위

- 수정된 인게임 한국어 819개와 UI·메시지 85개를 다시 읽었습니다. 첫 출력에서 잘린 115~142는 별도로 다시 읽었습니다. 1차에서 영어·한국어를 전부 대조한 뒤, 이번에는 한국어 전체를 다시 읽고 지적 사항과 수정 영역을 집중 확인했습니다. 영어 819개를 이번에 다시 전부 출력해 대조한 것은 아닙니다.
- `localization/glossary.json`의 123개 영어·한국어·키를 읽고, 기존 본편 참조의 `enGB.json.strings`와 `translation.json.data`를 같은 키로 연결하여 123개 전부를 기계적으로 대조했습니다. 122개는 양쪽 문자열이 정확히 맞았으며, Align Weapon 1개는 한국어가 달랐습니다.
- 본편 Earth Breaker의 여러 동일 명칭 키와 Heroism, Greater 및 Maximize 명칭도 직접 조회했습니다.
- `SecondPhaseFeature.cs` 전체를 읽었습니다. `SuperBuff.cs`의 상급 투명화 주석, 선 성향 무기 버프, 상급 영웅심 버프 참조도 확인했습니다. 추가된 `docs/source-discrepancies.md`를 읽었습니다.
- Enhance의 전체 재검토는 하지 않았습니다. 상대 평가는 1차의 29개 표본을 기반으로 합니다.

## 남은 수정 사항

### P2-1. 중간, 승인 전 수정: `StartingWeaponEarthbreaker.Description`

- 영어: `You start with a cold iron earthbreaker.`
- 현번역: `한철 대지멸절자를 시작 무기로 얻습니다.`
- 문제: Devastator의 ‘파괴자→멸절자’ 변경이 기존 ‘대지파괴자’에도 적용된 것으로 보이는 새 용어 오류입니다. 치환 경위를 직접 확인하지는 않았지만, 결과가 본편 용례와 다른 것은 확실합니다.
- 본편 근거: `6db0bd68-7267-4afb-8a69-13dc7bfdb458`에서 `Earth Breaker`는 `지진망치`입니다. `25e13051-043c-422c-8d8f-d0612c007626` 등 다른 동일 명칭도 같습니다.
- 권장 수정문: **`한철 지진망치를 시작 무기로 얻습니다.`**
- 용어집에도 Earth Breaker의 원래 명칭과 키를 추가하는 편이 안전합니다.

### P2-2. 중간, 승인 전 수정: `glossary.json`의 Align Weapon 및 `SuperBuff.Description`

- 영어 용어: `Align Weapon`
- 용어집 현번역 및 SuperBuff의 표기: `무기 성향 부여 (선)`
- 문제: 용어집에 보존한 `37739c2d-f007-4fd2-9cbf-875ef73776bf`의 실제 한국어는 **`성향 무기`**입니다. 현재 용어집은 번역자가 풀어 쓴 문구를 원본 키와 함께 원본 용어처럼 기록하고 있습니다. 효과의 선 성향은 `SuperBuff.cs`의 `AlignWeaponGoodBuff` 참조로 설명할 수 있지만, 원본 용어 자체와는 구분해야 합니다.
- 권장 수정: 용어집의 한국어를 **`성향 무기`**로 복원합니다. SuperBuff 목록에서는 **`성향 무기 (선)`**을 사용합니다. 별도 번역을 유지하려면 원본 용어와 의도적인 표시명 변경을 구분해 기록해야 합니다.

### P2-3. 낮음, 개선 권고: `SuperBuff.Description`의 목록 구분

- 현번역 일부: `거짓 생명, 상급, 피어나는 영광`, `엔젤의 형상, 상급, 복수의 돌풍`, `영웅심, 상급, 반향`
- 문제: 본편 고유 명칭 안에 쉼표가 들어 있는데, 목록도 쉼표로만 구분되어 ‘상급’이 독립 효과처럼 보입니다. 이름을 본편과 맞춘 방향은 적절하지만 목록 형식을 함께 바꿔야 읽기 쉽습니다.
- 권장 수정: 안내문 뒤에 줄바꿈을 넣고 모든 효과를 한 줄에 하나씩 나열하거나, 항목 구분자를 세미콜론으로 통일합니다. 예: **`… 이동의 자유; 거짓 생명, 상급; 피어나는 영광; … 질서의 방패; 엔젤의 형상, 상급; 복수의 돌풍; … 급소 감지; 영웅심, 상급; 반향; …`**
- 같은 용어 일관성 개선으로 `GoldBarrierHeroism.Description`도 **`10레벨에 황금 장벽이 아군에게 ‘영웅심, 상급’ 효과도 부여합니다.`**처럼 본편 이름을 인용할 수 있습니다. 현재 ‘상급 영웅심’도 의미는 정확하므로 승인 차단 사항은 아닙니다.

### P2-4. 낮음, 개선 권고: `SecondPhaseBuffEffect.Description`

- 현번역: `크기 변화로 힘에 +2, 민첩에 -2 크기 보너스가 추가로 적용됩니다.`
- 문제: 수치와 descriptor는 소스에 맞지만, 플레이어 문구에서 음수 값을 ‘보너스’라고 부르면 어색합니다.
- 권장 수정문: **`모든 능력치에 +10 불경 보너스를 받고 크기가 한 단계 커집니다. 크기 변화로 힘에 +2, 민첩에 -2의 크기 수정치가 추가로 적용됩니다.`**
- 이 항목은 별도 버프 정의에 관한 설명입니다. 부활 시 실제로 이 버프를 얻는다고 서술하지 않은 현재 방침이 맞습니다.

## 효과 정합성과 긍정적 확인

- SecondPhase는 DeathActions에서 완전 회복 부활 후 강화 버프를 **제거**하고, 자신도 제거합니다. 휴식 트리거가 부활용 버프를 다시 부여합니다. 따라서 현재 본문이 ‘휴식마다 한 번, 사망하면 완전 회복 부활’만 약속하는 것은 소스와 부합합니다. 독립 강화 버프에 +10 불경 능력치, 크기 +1, 힘 +2·민첩 -2 Size descriptor가 존재하는 것도 직접 확인했습니다.
- Bolster의 확산 주문, Empower의 강화 주문은 본편 키 대조로 확인했습니다. 자동 능력명과 본문에서도 올바르게 구분됩니다. 기존 번역으로 되돌릴 이유가 없습니다.
- 한철, 겁먹음, 구토, 고통, 멸절자, 포샤드 등은 해당 본편 키와 맞으며, 연결된 면역·혈통·소환 문장에도 일관되게 반영되었습니다.
- 일반 서술의 ‘고통’이나 ‘메스꺼울지도’까지 상태명으로 기계적으로 바꾸지 않아 문맥의 자연스러움이 유지되었습니다.
- `AutoMaximize.Description`의 ‘주문 극대화’는 본편 ‘극대화 주문’과 어순만 다릅니다. 엄격히 통일하려면 **`시전하는 모든 주문에 극대화 주문 특기의 효과가 자동으로 적용됩니다.`**로 다듬을 수 있으나 의미상 오류는 아닙니다.

## 남은 검증 경계

문장 전체를 읽고 알려진 수정 사항과 일부 코드를 대조했지만, 모든 능력의 외부 Blueprint·전투 처리·레벨 변화·재활성화 경로를 전수 검증하지 않았습니다. 부모가 보고한 생성 검사와 819개 모델 테스트 통과는 이번 리뷰가 독립적으로 재실행한 결과가 아니며, 실제 게임 동작 확인과도 별개입니다. 실제 UI에서 긴 SuperBuff 목록의 줄바꿈과 화면 잘림은 별도 확인이 필요합니다.

## Key Learnings:

1. 본편 용어를 일괄 치환할 때는 긴 무기명 내부의 부분 문자열까지 바뀌지 않는지 확인해야 합니다.
2. 쉼표를 포함한 공식 주문명은 쉼표로 나열하지 말고 줄바꿈이나 세미콜론으로 구분하면 명칭의 경계가 분명해집니다.
