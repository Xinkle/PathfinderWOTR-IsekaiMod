# Astra-low 번역 품질 리뷰: 3차 최종 판정

## 최종 판정

**현재 확인 범위에서 번역 품질을 승인합니다. 남은 승인 차단 문제는 발견하지 못했습니다.**

사용자가 요청한 WOTR-Enhance 대비 ‘준수한 정도’에는 도달했다고 판단합니다. 1차에서 읽은 Enhance 29개 표본과 비교하면 Isekai는 직역투가 적고, 규칙 설명과 패러디 대사의 어조도 자연스럽게 구분합니다. 본편 용어를 직접 대조하고 원문·코드 불일치까지 별도 기록한 점도 긍정적입니다. 이는 Enhance 전체 1,637개보다 우수하다는 전수 비교 판정이 아닙니다.

## 이번에 실제 확인한 범위

- 이번 3차에서는 전체 819개와 UI 85개를 다시 읽지 않았습니다. 전체 한국어 재독은 2차에서 수행했습니다.
- 다음 6개 항목을 읽었습니다: `StartingWeaponEarthbreaker.Description`, `SuperBuff.Description`, `AutoMaximize.Description`, `GoldBarrierHeroism.Description`, `SecondPhaseBuffEffect.Description`, `SecondPhase.Description`.
- 용어집 124개의 `SourceKey`를 기존 본편 참조의 `enGB.json.strings`와 `translation.json.data`에 연결하여 영어·한국어를 모두 기계적으로 재대조했습니다. **124개 전부 정확히 일치했으며 불일치는 0개입니다.**
- Align Weapon과 Earth Breaker의 원본 및 표시명 필드를 직접 읽었습니다. 이번에는 전체 효과 소스를 다시 조사하지 않았습니다.

## 승인 차단 사항 해소

| 2차 항목 | 3차 확인 |
| --- | --- |
| P2-1: Earth Breaker 오역 | `한철 지진망치를 시작 무기로 얻습니다.`로 수정되었습니다. 용어집 원본 키도 본편의 `Earth Breaker / 지진망치`와 일치합니다. |
| P2-2: Align Weapon 근거 불일치 | 원본 `Korean`은 `성향 무기`로 복원되었습니다. `성향 무기 (선)`은 `DisplayKorean`에 분리하고 선 성향 버프 근거를 `DisplayNote`에 기록했습니다. SuperBuff 표시명도 이에 맞습니다. |

## 남은 낮은 우선순위 사항

다음은 의미를 잘못 전달하거나 승인을 막는 문제는 아닙니다. 마무리 교정 시 반영하면 좋습니다.

1. **`SuperBuff.Description`**: 대부분 세미콜론으로 분리되어 주문명 내부 쉼표를 구별할 수 있습니다. 다만 항목 사이 쉼표 두 곳이 남았습니다.
   - 현번역: `은총 부여, 상급 용기의 오라`
   - 권장: **`은총 부여; 상급 용기의 오라`**
   - 현번역: `성전사의 칼날, 상급 마법 무기`
   - 권장: **`성전사의 칼날; 상급 마법 무기`**
   - `거짓 생명, 상급`, `엔젤의 형상, 상급`, `영웅심, 상급`의 내부 쉼표는 유지합니다.
2. **`SecondPhaseBuffEffect.Description`**: 수치와 보너스 유형은 맞습니다. 다만 음수 보너스까지 포함하므로 `크기 변화로 힘에 +2, 민첩에 -2의 크기 수정치가 추가로 적용됩니다.`가 더 자연스럽습니다.
3. **`AutoMaximize.Description`**: `주문 극대화 특기`도 의미는 명확하지만, 본편 이름 그대로 `극대화 주문 특기`로 통일할 수 있습니다.
4. **`GoldBarrierHeroism.Description`**: `상급 영웅심`도 의미는 명확합니다. 본편 표시명에 엄격히 맞추려면 `10레벨에 황금 장벽이 아군에게 ‘영웅심, 상급’ 효과도 부여합니다.`로 다듬을 수 있습니다.

## 검증 경계

- 번역 품질 승인은 전체 빌드 성공, 게임 실행 성공, 배포 승인과 별개입니다.
- 모델 테스트와 생성 검사 통과를 실제 게임에서의 번역 적용이나 효과 동작 확인으로 해석하지 않습니다. 이번 3차에서는 해당 테스트를 독립적으로 다시 실행하지 않았습니다.
- 긴 SuperBuff 목록의 실제 화면 줄바꿈·잘림, 각 능력의 외부 Blueprint 및 런타임 동작은 실기 검증 대상입니다.
- 알려진 원문·효과 불일치를 번역에서 보수적으로 처리한 것은 적절합니다. 게임플레이 결함 자체가 수정되거나 모든 동작이 검증되었다는 뜻은 아닙니다.

## Key Learnings:

1. 원본 용어와 문맥에 맞춘 표시명을 별도 필드로 보존하면 출처의 정확성과 읽기 쉬운 UI 표기를 함께 유지할 수 있습니다.
2. 번역 품질 승인과 전체 빌드·실기 검증은 서로 다른 결과로 보고해야 합니다.

## 재확인 부록: 마무리 권고 해소

최종 보고서 작성 뒤 수정된 `ko-kr.json`에서 다음 네 항목을 직접 다시 읽고 확인했습니다.

- `SuperBuff.Description`: `은총 부여; 상급 용기의 오라`와 `성전사의 칼날; 상급 마법 무기`로 구분되었습니다. 주문명 내부 쉼표는 유지되었습니다.
- `GoldBarrierHeroism.Description`: 본편 이름인 `‘영웅심, 상급’`을 인용합니다.
- `AutoMaximize.Description`: `극대화 주문 특기`로 어순을 통일했습니다.
- `SecondPhaseBuffEffect.Description`: `힘에 +2, 민첩에 -2의 크기 수정치`로 수정되어 음수 보너스라는 어색한 표현이 해소되었습니다.

위 네 항목에서 새 문제는 발견하지 못했습니다. **이 리뷰에서 제시한 낮은 우선순위 권고도 모두 해소되었으며, 남은 미적용 권고나 승인 차단 사항은 없습니다. 번역 품질 승인 판정을 유지합니다.** 본문에 남겨 둔 권고 목록은 수정 전 검토 이력입니다. 이번 추가 확인은 네 항목에 한정하며, 전체 텍스트 재독이나 전체 빌드·실기 검증을 뜻하지 않습니다.

## 최종 코드 대조 부록: MindControl 내성 표시

`IsekaiMod/Content/Features/IsekaiProtagonist/OverpoweredAbility/MindControl.cs` 전체와 `TTCoreExtensions.CreateBuff` 구현, 관련 심벌 참조 및 카탈로그의 `MindControl.SavingThrow` 항목을 확인했습니다.

- 능력은 `AbilityEffectRunAction`에서 `MindControlImmunity` 보유 여부로 분기합니다. 면역 버프가 있으면 그 버프를 1분간 다시 부여하고, 없으면 지배 버프를 직접 부여합니다.
- 지배 버프는 `ChangeFaction.ToCaster`로 진영을 바꾸고, 해제될 때 면역 버프를 부여합니다. 버프 자체에도 반복 의지 내성 처리가 없습니다.
- 능력의 나머지 component는 주문 학파, 캐릭터 레벨 랭크, 자원 사용을 설정합니다. 이 소스에는 최초 적용 또는 유지에 내성 굴림을 요구하는 action/component가 없습니다. CreateBuff wrapper도 내성 처리를 추가하지 않습니다.
- `LocalizedSavingThrow`의 `Will negates`는 표시용 원문과 실제 구성 사이의 불일치입니다. 따라서 자체 `MindControl.SavingThrow`를 **`내성 없음`**으로 정정한 판단은 정적 소스 기준으로 타당합니다. 카탈로그의 Evidence와 불일치 문서도 같은 근거를 기록하고 있습니다.

이 변경에서 새로운 승인 차단 문제는 발견하지 못했습니다. **번역 품질 승인 판정을 유지합니다.** 이 결론을 별도 서큐버스 능력에 적용하거나 그 본편 내성 문자열을 변경할 근거는 없습니다. 또한 ‘내성 없음’은 모든 대상에게 반드시 성공한다는 뜻이 아니며, 이미 구현된 면역 버프 조건이나 기타 게임 런타임 제한까지 없다고 단정하지 않습니다. 이번 확인은 해당 소스와 표시 문구의 정합성 검토이며 실기 검증은 아닙니다.
