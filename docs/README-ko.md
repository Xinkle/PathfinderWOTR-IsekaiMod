# Isekai Mod 한국어 번역판 5.4.4

원본 Isekai Mod에 한국어 번역을 내장한 포크입니다. 별도 번역 모드가 아닙니다.
원 저자는 Info.json의 JohN100x1이며 원본 프로젝트의 저작권·라이선스를 유지합니다.
기준 소스는 New-Isekai-2.0의 e4d5ac3입니다. 미병합 버그 수정 PR이나 베타를 포함하지 않습니다.

## 포함 내용

- 게임 문구 819개와 UMM 설정창·플레이어 메시지 85개를 번역했습니다.
- 일부 오래된 설명은 실제 구현에 맞춰 번역했으며 전투·성장·밸런스 코드는 변경하지 않았습니다.
- WOTR-Enhance 없이 번역이 동작하도록 구현했습니다. TTT 전체 번역은 포함하지 않습니다.
- 원래 모드 ID는 IsekaiMod이며 기존 Isekai 모드와 같은 모드로 취급됩니다.

## 요구 사항과 설치 주의

- 원본 요구 사항: Unity Mod Manager 0.24.0 이상, TabletopTweaks-Core 0.6.2 이상.
  의존 모드는 이 ZIP에 포함하지 않습니다. 원본이 요구하는 게임 환경이 필요합니다.
- 기존 Isekai 모드와 설정·저장 파일을 별도로 백업하고, 게임을 종료한 뒤 설치하세요.
- UMM에서 이 ZIP을 설치하거나 ZIP의 IsekaiMod 폴더를 게임의 Mods 아래에 놓습니다.
  동일 ID의 기존 설치가 있으면 중복 폴더를 만들지 말고 기존 설치 위치를 확인하세요.
- 기존 Settings.xml, AddedContent.json 등 개인 설정은 이 ZIP에 넣지 않았습니다.
  업데이트할 때 기존 설정을 삭제하거나 기본 설정으로 덮어쓰지 마세요.
- enGB와 esES에서 한국어를 표시합니다. 다른 언어는 원래 표시를 유지합니다.
- 이 포크의 내장 번역을 위해 WOTR-Enhance나 별도 KoreanTranslationOverride 설치가 필수인 것은 아닙니다.

## 검증 상태

**인게임 미검증 사전 릴리스입니다.**

- 게임 PC의 참조 DLL로 전체 Rebuild를 수행하여 경고 0개·오류 0개를 확인했습니다.
- 원문·태그·변수·누락, 단위 검사, Harmony 모델 검사와 API 부분 컴파일을 통과했습니다.
- Astra-low와 3차 번역 품질 검토를 진행하고 지적 사항을 반영했습니다.
  WOTR-Enhance 29개 비교 표본에 준하는 품질 판정이며 전수 비교는 아닙니다.
- 실제 UMM 로드, 설정 저장, 전투 동작, 글꼴·줄바꿈·잘림과 다른 모드 공존은 확인하지 않았습니다.
- 원본 게임플레이 결함과 저장 호환성을 모두 해결하거나 보장한 릴리스가 아닙니다.
  새 테스트 저장 파일이나 백업 저장 파일로 확인하는 것을 권장합니다.

상세 근거는 포크 저장소의 docs/localization.md, docs/source-discrepancies.md,
docs/build-and-validation.md 및 docs/reviews/에서 확인할 수 있습니다.
