# Isekai 자체 한국어 번역: 작성 및 품질 검수 완료

2026-10-21. **번역 작성과 Astra-low 품질 리뷰 루프를 마쳤습니다.**
후속 요청으로 게임 PC에서 누락 참조를 확보하고 현재 게임 DLL의 로컬 공개화 사본을 만들어,
전체 모드 DLL Rebuild도 0 경고·0 오류로 통과했습니다.
설치 가능한 배포본이나 인게임 검증이 완료된 릴리스라는 뜻은 아닙니다.

기준 브랜치는 `localization/ko-kr`, 기준 커밋은
`e4d5ac3bf57c9b644fe5d1000e69a5a6ed1a26df`입니다.
master, V3 Git 태그, 미병합 수정 PR로 기준을 변경하지 않았습니다.
원 저자와 모드 ID는 유지하며, 로컬 후보 버전은 **5.4.4**입니다.

## 번역 범위와 정합성

- `localization/ko-kr.json`: 인게임 **819개 표시 정체성**과 UMM·플레이어
  메시지 **85개**입니다. 원문·키·템플릿 여부·한국어·근거를 분리합니다.
- 클래스·전형·전승·특기·능력·버프·혈통·배경·신격·대화·시작 무기 설명,
  UMM 전체 표시 및 상인 결과 메시지 44개를 작성했습니다.
- 영문 `...` 반응은 구두점만 있는 의도적인 불변 항목입니다. 원문의 `TBD`는
  `설명 준비 중입니다.`로 표시하며 효과를 임의로 만들어 설명하지 않습니다.
- 본편이나 다른 모드에서 상속한 LocalizedString은 기존 표시를 사용합니다.
  본편 전체 영어를 이 모드가 무차별 번역하지 않습니다.
- 동봉 팩 818개 중 현재 소스와 대응하는 **785개 행**을 번역에 포함하고,
  과거 문구 **33개**는 `obsolete-entries.json`에서 근거와 함께 분리했습니다.
  현재 원문/템플릿 조합 중 **35개**는 옛 팩에 없거나 변경된 조합입니다.
  중복 표시 정체성을 합친 최종 자체 카탈로그가 819개입니다.
- `runtime-targets.json`은 생성된 이름, 배경·소환의 공통 접미문,
  읽기 전용 문자열 필드·지역 변수, 선택적 모드 지원까지 포함한 정적 재구성
  목록입니다. 770개 등록/표시 호출과 135개 factory 호출을 조사했습니다.
  실제 게임에서 모든 조건부 경로를 실행한 결과는 아닙니다.

## 구현과 보존 원칙

`Main.Load`에서 컨텍스트가 만든 기존 언어 팩을 바인딩한 뒤, Blueprint 등록
전에 표시 패치를 설치합니다. 생성 C# 데이터가 자체 DLL에 들어가므로
Enhance 설치는 필요하지 않습니다. Enhance의 TTT 번역 카탈로그는 포함하지 않습니다.

- 영어 `enGB`, 다른 언어 필드, 기존 GUID·Blueprint ID를 변경하지 않습니다.
- 바인딩한 Isekai 팩에 속한 문자열 객체에만 번역을 적용합니다. 다른 모드의
  같은 키·같은 영어도 가로채지 않습니다.
- 키가 같아도 영어와 템플릿 여부가 바뀌면 이전 번역을 적용하지 않습니다.
  GUID가 달라진 경우 정확한 영어·템플릿 조합의 번역이 하나로 정해질 때만
  fallback을 허용합니다. null 카탈로그 키는 런타임 GUID 생성 지시가 아닙니다.
- AddString의 영어 인덱스를 보존하도록 중첩·예외 안전 가드를 둡니다.
  이미 게시된 항목은 가드 밖에서 표시 엔트리를 재생성합니다.
- `enGB`와 `esES`에서 한국어를 표시합니다. 기존 한국어 게임 환경과 Enhance의
  매핑에 맞춘 선택입니다. 다른 언어는 유지합니다. 이 포크에서 순수 영어
  사용자도 해당 두 언어를 선택하면 한국어를 보게 됩니다.
- TTT 템플릿 처리와 원문의 태그·링크·서식·변수를 보존합니다.
  별도 한글 글꼴 패키지는 포함하지 않으며 실제 글꼴·줄바꿈 확인은 남아 있습니다.
- KoreanTranslationOverride와 XinkleWotrEnhance 뒤에서 처리하도록 순서를
  지정했습니다. 실제 Unity 환경의 공존은 별도로 확인해야 합니다.
- UMM 그룹·설명·제목만 번역합니다. 저장용 영어 키, Description 값, 기본값과
  사용자가 선택한 설정은 번역 때문에 바꾸지 않습니다.
- 팩 등록과 UI는 정상적인 게임 메인 스레드 수명주기를 전제로 합니다.
  여러 스레드가 팩을 동시에 수정하는 기능을 추가하지 않았습니다.

## 코드와 설명이 다른 경우

게임플레이 소스를 고치지 않고 실제 설정을 기준으로 설명했습니다.
상세 근거와 미확인 부분은 [불일치 목록](source-discrepancies.md)에 있습니다.

대표 사례는 Ascension +15, Instakill의 불경 피해 1, PerfectRoll +5,
ForbiddenSummoning 생명력 계수 5, TrainingMontage의 두 보너스 합산,
PowerLeveling의 무조건 아군 오라, SecondPhase의 강화 버프 미부여입니다.
자원 성장·외부 Blueprint 동작·자동 레벨 갱신 등 확인하지 못한 동작은
정상 작동한다고 단정하지 않았습니다. 원본 게임플레이 결함은 그대로 남아 있습니다.

## 용어와 Astra-low 리뷰 루프

기존 본편 한국어 캐시와 Enhance의 검토된 번역을 읽기 전용으로 대조했습니다.
`glossary.json`에 124개의 짧은 용어와 원래 키를 보존합니다.
예: 한철, 겁먹음, 고통, 구토, 멸절자, 확산 주문, 강화 주문.
이세계 주인공 / 전승 / 초월 능력 / 특수 능력 / 중2병 군주 /
신황 / 용사 / 책략가 / 패왕을 자체 콘텐츠 용어로 사용합니다.
전역 런타임 단어 치환은 사용하지 않습니다.

1. **1차**: Astra-low가 인게임 819개와 UI 85개를 전부 읽고, Enhance 29개
   표본과 비교했습니다. 조사 오류, 소환 보너스의 범위 모호성, 버프 효과 누락을
   발견했습니다. 선택적 자연스러움 개선까지 모두 반영했습니다.
2. **2차**: 전체 문구를 다시 읽고 본편 용어 키를 대조했습니다. 지진망치 오역과
   Align Weapon의 원본/표시명 구분을 수정했습니다.
3. **3차**: 수정 부분과 용어집 124개를 다시 확인했습니다. 낮은 우선순위의 목록
   구분자·어순 교정까지 반영한 뒤 **미적용 권고와 승인 차단 사항이 없다는
   번역 품질 승인**을 받았습니다.

[1차](reviews/astra-low-pass1.md), [2차](reviews/astra-low-pass2.md),
[3차 최종 판정](reviews/astra-low-pass3.md)을 보존했습니다.
평가는 **Enhance 비교 표본 대비 ‘준수한 정도’**입니다. Enhance 전체 1,637개보다
우수하다는 전수 비교 판정이나 모든 효과 코드의 독립 검증은 아닙니다.

## 검증 상태와 남은 외부 검증

생성·태그·누락 검사, Python 단위 검사, 819개 Harmony 모델 검사와
실제 게임·TTT API를 참조한 번역/UMM 부분 컴파일을 수행했습니다.
범위와 결과는 [빌드 문서](build-and-validation.md)와 `local-validation.json`에 있습니다.

전체 DLL 빌드는 사용자 후속 요청에 따라 게임 PC에서 누락 참조를 확보한 뒤 통과했습니다.
공개화한 게임 DLL은 로컬 빌드 참조일 뿐이며 배포하거나 게임에 설치하지 않습니다.
설치는 별도 승인이 필요합니다.
게임에서 다음 사항을 별도로 검증해야 합니다.

- UMM 로드, 설정 OFF 보존·저장·재시작, 외형 선택과 긴 설명 표시.
- 기본 클래스·전형·혈통·배경·대화·조건부 외부 모드 콘텐츠 표시.
- 언어 전환, 레거시 번역 모드 공존, 영어 인덱스와 반복 시작 시 GUID 중복 방지.
- 원본 결함으로 기록된 능력의 실제 동작과 글꼴·레이아웃.

다른 저장소는 수정하지 않았습니다. 원격 접속은 사용자 요청에 따른 참조 파일의
읽기 전용 조회·다운로드만 수행했습니다. 사용자 후속 요청으로 커밋·푸시와 포크 저장소의 ZIP 사전 릴리스 발행을
승인받았습니다. PR·게임 PC 설치·게임 실행은 수행하지 않습니다. Xync 기록은 아직 승인되지 않았습니다.
Engram의 호스트 등록 신원이 없으므로 attributed memory 쓰기는 수행하지 않았습니다.
