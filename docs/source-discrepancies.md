# 코드·문구 불일치와 미확인 동작

기준: e4d5ac3. 이 문서는 결함 발견 기록이며 게임플레이 수정 승인이 아닙니다.
모든 항목은 정적 소스 조사이며 실제 게임 동작을 확인하지 않았습니다.

배경의 추가 설명과 소환 설명은 `Utilities/ExtensionMethods.cs`에서 접미문을
붙입니다. 문자열 조각만 번역하면 전체 등록 문자열과 일치하지 않으므로,
이 영역은 완성된 런타임 원문을 재구성한 후 번역해야 합니다.

미병합 수정 PR이 위 문제를 해결한다고 가정하지 않았으며 해당 코드를 가져오지
않았습니다. 본문 번역이 남은 항목을 제외하고 모든 효과를 검증했다고 주장하지
않습니다. 새 발견은 근거 위치와 확인 수준을 명시해 이 문서에 추가하세요.

## 전체 초안 작성 중 추가 확인한 사항

- **Instakill**: `Instakill.cs:55-76`의 실패 분기는 `ContextActionDealDamage`로
  불경 피해 1을 적용합니다. 코드 주석의 “HP를 1로 감소”와 설명의 즉사는
  둘 다 실제 설정과 다릅니다. 성공 분기는 1라운드 기절입니다. 난이도 25와
  레벨·매력 성장 공식은 확인하지 못했으므로 번역에서 단정하지 않습니다.
- **PerfectRoll**: `ModifyD20.AddBonus=true`, 고정 보너스 5입니다. 항상 20이
  나오게 하는 능력이 아닙니다.
- **PowerLeveling**: 반경 120피트 아군 오라가 조건 없이 명중과 인내 내성에
  각각 +2를 줍니다. 처치 조건, 경험치 배율, 다른 내성 보너스는 없습니다.
- **ForbiddenSummoning**: 설명은 레벨당 생명력 +10이지만 실제 HP component의
  Multiplier는 5입니다. 한국어는 +5로 정정했습니다.
- **TrainingMontage**: 별도 기본 +2와 활성화 시
  `min(2 + CharacterLevel / 4, 8)`이 합산됩니다. 활성화 시점의 합계는
  1레벨 +4, 20레벨 +9입니다. 자동 레벨 갱신 handler가 없으므로 지속 보유 중
  갱신은 실기 미확인입니다. 설명의 1레벨 +2·20레벨 +8을 되풀이하지 않습니다.
- **FriendlyAura 버프**: 원문은 명중 -4만 설명하지만 같은 버프가 피해에도
  -4를 부여합니다. 버프 한국어 설명을 보완했습니다.
- **SecondPhase**: 부활 분기는 강화 버프를 적용하는 대신 제거합니다.
  따라서 부활 후 +10 능력치·크기 증가·24시간 효과를 약속하지 않습니다.
  독립된 강화 버프 정의에는 +10 불경 능력치와 크기 +1 외에 힘 +2·민첩 -2의
  크기 수정치도 있습니다. 정상 부활 경로에서는 이 버프가 부여되지 않습니다.
- **DeusExMachina / SecondReincarnation / SecondPhase**: HP 0 검사 자체가 아니라
  `DeathActions`에서 부활하며 소비한 트리거는 `AddRestTrigger`로 재부여합니다.
  “휴식마다 한 번, 사망하면”으로 기술했습니다.
- **Exalted Choir**: 원문 능력 설명에는 님프가 남아 있지만 실제 생성 action은
  서큐버스·아스트랄 데바·에리니에스 세 개입니다. 한국어에서는 님프를 제외했습니다.
- **SuperBuff**: 상급 투명화는 목록에서 주석 처리되어 있습니다. 실제 아군
  반경은 60피트입니다. 해제는 목록에 있는 같은 시전자의 버프만 제거하며,
  다른 모든 버프를 무차별 해제하는 동작이 아닙니다.
- **DodgeMaster의 잘못된 참조**: 이동 시 기회 공격 면역이라는 설명과 달리,
  추가하는 GUID `c6147854641924442a3bb736080cfeb6`는 읽기 전용 캐시에서
  `SummonNaturesAllyI`의 BlueprintAbility입니다. 소스는 이를 BlueprintFeature로
  조회합니다. 이 참조의 실제 오류·로드 영향은 실기 미확인이며 수정하지 않았습니다.
  번역에는 확인된 방어도 +4 회피 보너스만 표시합니다.
- **죽음강탈자 독침**: 캐시의 원본 feature는 건강 기반의 동적 난이도를 사용합니다.
  연결된 독 버프는 1d4 건강 피해를 설정합니다. 고정 DC 28은 단정하지 않습니다.
  실제 독 반복 시점과 내성 처리는 게임 검증이 필요합니다.

위 캐시 확인은 게임 2.7.0x 조사 캐시에 대한 정적 조사입니다. 현재 설치 파일을
새로 조회하거나 실행한 결과가 아니며, 다른 게임 버전까지 동일하다고 주장하지
않습니다. 원본 DLL·Blueprint JSON 전체를 저장소에 넣지 않았습니다.

### 정신 지배의 내성 표시

`MindControl.cs:72-100`은 정신 지배 면역 버프를 조건으로 분기한 뒤 지배 버프를
직접 부여하며, 내성 굴림 action이나 내성 처리를 추가하지 않습니다.
그런데 표시용 `LocalizedSavingThrow`만 `Will negates`로 설정되어 있습니다.
자체 `MindControl.SavingThrow` 한국어는 `내성 없음`으로 정정했습니다.
별도 서큐버스 매혹 능력이 상속한 본편 내성 문자열은 변경하지 않습니다.
